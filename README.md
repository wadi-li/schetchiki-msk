# Учёт воды и электроэнергии (Москва)

Автономная HTML-программа для учёта показаний трёхтарифного электросчётчика (T1 пик, T2 ночь, T3 полупик) и счётчиков воды (ХВС, ГВС) по тарифам г. Москвы для населения. Работает без интернета и установки — достаточно открыть `schetchiki.html` в браузере.

## Возможности

- Ввод показаний с датой, расчёт расхода в кВт·ч и литрах и начислений в рублях; водоотведение = ХВС + ГВС.
- Автоматический подбор тарифа: по дате показаний, по расчётному месяцу или пропорционально дням между показаниями.
- Встроенные тарифы 2026–2027 гг. (газовая плита и электроплита) с основаниями: приказы ДЭПиР ДПР-ТР-407/25, ДПР-ТР-334/25, ДПР-ТР-316/25, протокол ДПР-П-21.10-1/26.
- Переключение «газовая плита / электроплита» для всех записей или только для новых.
- Проверка отрицательного и подозрительно большого расхода, отметка замены счётчика.
- Учёт двух платежей: ЕПД (вода) и Мосэнергосбыт — сумма и дата оплаты.
- Средний расход за квартал, полгода, год и произвольный период — в единицах или рублях.
- Графики с переключением типа, единиц, отключением групп и рядов.
- Отчёты CSV (разделитель `;`, UTF-8 с BOM), HTML с графиками, MD, TXT.
- Квитанция арендатору в TXT, MD, CSV и PDF с реквизитами, суммой прописью, подписью и печатью.
- Резервная копия в JSON: сохранение, восстановление с заменой или объединением, отмена восстановления, напоминание.
- Светлая тема по умолчанию и тёмная тема.

## Как пользоваться

1. Откройте `schetchiki.html` в браузере (Chrome, Edge, Firefox).
2. Выберите тип плиты в верхней панели.
3. Первая запись задаёт начальные показания. Далее вводите показания каждый месяц, а после оплаты — суммы и даты платежей.
4. Регулярно нажимайте «Сохранить копию»: данные хранятся в браузере этого компьютера.
5. Квитанция в PDF: вкладка «Отчёты» → реквизиты → «PDF» → в окне печати «Сохранить как PDF».
6. При новой индексации добавьте период на вкладке «Тарифы».

`primer_kvitancii.pdf` — пример квитанции на тестовых данных.

Тарифы приведены для Москвы, кроме ТиНАО. Перед использованием сверяйте их с актуальными приказами на [tarif.mos.ru](https://tarif.mos.ru/).
